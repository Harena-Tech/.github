# Harena Tech · Organização GitHub

Bem-vindo à organização oficial da **Harena Tech** no GitHub!

Somos uma empresa de tecnologia dedicada à criação e validação de soluções digitais inovadoras. Utilizamos este espaço para organizar e versionar nossos projetos de forma colaborativa e estruturada.

## 🧭 Estrutura da Organização

Nossos repositórios são divididos em três categorias principais:

### 🧪 Projetos Internos
Soluções desenvolvidas e mantidas pela própria Harena Tech, com foco em produtos proprietários e escaláveis.

### 🤝 Parcerias Estratégicas
Projetos construídos em colaboração com outras startups ou instituições, onde atuamos como cofundadores técnicos ou parceiros de produto.

### 🛠️ Prestação de Serviços
Soluções criadas sob demanda para empresas, órgãos públicos ou clientes que contratam a Harena Tech como fornecedora de tecnologia.

## 📌 Organização e Gestão

Para garantir alinhamento e transparência no desenvolvimento, utilizamos:

### 📋 GitHub Projects
Cada projeto ativo possui um **quadro no GitHub Projects** com o fluxo Kanban adaptado à nossa metodologia interna. Esse quadro é utilizado para organizar tarefas, acompanhar entregas e priorizar demandas com clareza.

- Status das tarefas: A Fazer · Em Andamento · Em Validação · Concluído
- Critérios de aceitação definidos nas issues
- Priorizações com base no método MoSCoW

### 🎓 Metodologia Interna e Responsabilidades
Todos os membros e colaboradores devem seguir nosso modelo ágil, que inclui:

- Kanban contínuo
- Priorização por MoSCoW
- Matriz de responsabilidades por módulo
- Critérios claros de entrega
